HMS / Stoffkartotek — профессиональный режим

Справочник использует отдельный слой безопасности для профессиональной работы в Норвегии. SDS и этикетка производителя всегда имеют приоритет. Новая или изменённая химия без проверенной HMS-записи автоматически получает STOP.

Перед началом смены / работы

  • Проверить доступ к актуальному SDS/stoffkartotek для всей используемой химии.
  • Проверить маркировку рабочих бутылок: название средства, рабочее разведение и опасность — никаких пищевых бутылок.
  • Подготовить химстойкие перчатки и защиту глаз; дополнительные СИЗ — по SDS разделу 8.
  • Проверить вентиляцию, чистую воду для промывки и комплект для локализации пролива.
  • Если материал, химия или SDS не совпадают с карточкой — остановить работу и перепроверить.

Аварийная памятка

Глаза: при попадании химии начать промывание немедленно проточной водой, удерживая веки открытыми. Не откладывать промывание ради звонка.

Мастер очистки по элементу

Выберите элемент, степень и тип загрязнения. Справочник соберёт безопасный пошаговый план из химии SIR: разведение, инструмент, порядок работы, смыв, сушка и риски.

Лишнее / резерв — мастер автоматически не использует

  • Dasty Classic Degreaser — бытовой обезжириватель. В основном арсенале не нужен: для профессиональной схемы уже есть проверенные специализированные средства.
  • Optimizer / Generic Glass Cleaner — резерв. Основной стекольный состав: Koch-Chemie Glass Cleaner с подтверждённой инструкцией.
  • Luktborttagare / Luktfjerner 500 мл — резерв. Основной нейтрализатор после устранения источника запаха: Koch-Chemie Fresh Up.
  • Biltema Interior Cleaning Vinyl 36-0157 — резерв. Не назначается автоматически без полной актуальной техкарты именно этой версии.
  • Armor All Protectant Semi-Matt — резерв. Для ухода за внутренним пластиком основной проверенный состав: Koch-Chemie Top Star.
  • Служебное средство: Kärcher FoamStop neutral — не чистящая химия. Оставлено отдельной карточкой, но для Puzzi 8/1 автоматическое применение заблокировано до подтверждения совместимости.

Чего не хватает / что имеет смысл докупить

  • SDS для старой красной Gtechniq W4 именно этой legacy-формулы — до получения документа средство остаётся в HMS-карантине и не назначается мастером для клиентских работ.
  • CARPRO Eraser или эквивалентный подтверждённый paint-prep — нужен перед CARPRO Essence Plus; текущая инструкция Essence Plus предусматривает обезжиривание/подготовку поверхности.
  • TASKI Tapi Defoam либо другой пеногаситель, официально совместимый с выбранной схемой TASKI + экстрактор — нужен только при избыточной пене. Имеющийся Kärcher FoamStop не подставляется автоматически.
  • Отдельный повседневный очиститель дисков — для обычной дорожной грязи и тормозной пыли, чтобы Reactive Rust Remover не был средством «на каждую мойку».
  • Средство с подтверждённой совместимостью с дисплеями, рояльным глянцем и soft-touch — Green Star и Top Star мастер на такие поверхности автоматически не назначает.

Важно: Ecolab Carpet B удалён из рабочего инвентаря и мастера — на присланных 30 фотографиях этого средства нет. Для локальных жирных пятен используется имеющийся Fleckenwasser после обязательного теста материала.
