# SIR Rens & Pleie

Мобильный справочник по профессиональной автохимии.

## Открыть приложение

https://sir-rens-pleie.dear-pony-3227.chatgpt.site

## Возможности

- поиск химии по задаче и поверхности;
- фильтры: текстиль, кузов, пластик, кожа и защита;
- разведение и пошаговое применение;
- указание следующего средства;
- предупреждения по безопасности;
- установка на главный экран телефона.
